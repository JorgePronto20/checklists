FAQ

Perguntas frequentes

Como funciona o sistema de licenciamento? +
Após o pagamento ser confirmado, recebe por email um link direto para a aplicação e uma chave de licença única no formato XXXX-XXXX-XXXX-XXXX. Na primeira entrada, introduz a chave e fica com acesso pelo período da licença contratado.
A aplicação funciona offline? +
Em modo Demo (localStorage), sim — funciona completamente offline no browser. No modo Live com Cloudflare Workers, necessita de ligação à internet para sincronizar dados com a base de dados D1.
Os meus dados estão seguros? +
Sim. A API corre em Cloudflare Workers com CORS restrito ao seu domínio, sem dependências de terceiros. Em modo Demo, os dados ficam apenas no localStorage do seu browser. Em modo Live, a Cloudflare D1 garante armazenamento distribuído e seguro.
Posso migrar os dados entre planos? +
Sim. A funcionalidade de Export/Import JSON permite exportar todos os dados (colaboradores, modelos, checklists, alertas, atividade) e importá-los noutro plano ou instância.
Tenho de instalar algum software? +
Não. É 100% web-based. Abre no browser de qualquer dispositivo — PC, tablet ou telemóvel. Nada para instalar, nada para atualizar manualmente.
O que acontece quando a licença expira? +
Quando a licença expira, é apresentado o ecrã de ativação. Os dados ficam guardados localmente. Basta renovar e introduzir a nova chave para retomar o acesso imediato.
